# Data

This folder contains the HR dataset used for this project.

**Dataset:** Nigerian Financial Institution HR Records (2015–2024)
- 5,000 employee records
- 36 features
- Synthetic dataset generated to mirror real Nigerian banking HR data
- Target variable: Attrition (Yes/No)

The dataset was programmatically generated using `generate_hr_data.py`
in the root of this repository.
